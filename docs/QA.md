# Проверка объединённого приложения

Проверка 23 сентября 2026, macOS, Node.js 24.19.0. Ветки `backend` и `frontend` объединены; данные интерфейса обслуживает настоящий Fastify API с SQLite.

## Автоматические проверки

- `pnpm check`: frontend business rules, проверка TypeScript обоих проектов, backend API/SQLite/AI/client tests и HTTP-интеграция.
- `pnpm build:all`: production-сборки backend и Next.js.
- `npm run export:openapi --prefix backend`: актуальность API-контракта.
- HTTP-интеграция покрывает низкий рейтинг, сохранение компании и девяти полей, черновик/публикацию, конфликт версий, ручной выбор, повторное подтверждение XP и AI fallback. Тесты потери ответов проверяют безопасные повторы записи и отсутствие дублей.

## Проверено в браузере

- Каталог загрузился из backend; пять исходных опубликованных карточек имеют рейтинги 20/40/70/90/100.
- Пример брифа → шесть уточняющих вопросов через `/api/brief/analyze` с явной меткой «Демо AI».
- Заполнение редактируемой карточки, ручное подтверждение, публикация с рейтингом 100.
- Отправка предложения от серверной команды Qadam; ручной выбор бизнесом; отдельное принятие этапа.
- Перезагрузка страницы сохранила новую карточку, предложение и 100 XP команды в SQLite.
- На ширине 453 px горизонтального переполнения нет, меню сворачивается. В журнале браузера отсутствуют ошибки и предупреждения приложения.
- Фильтр «Черновик» показывает карточку с рейтингом 20; кнопка предложения остаётся доступной.
- Занятый порт останавливает общий launcher с сообщением о необходимости выбрать свободные порты.

## Границы проверки

Реальный внешний AI-провайдер не вызывался. Его транспорт, некорректные ответы, таймауты и проверка фактов покрыты локальными HTTP-тестами; реальный UI проверен с отсутствующим ключом и серверным fallback. Роли остаются демонстрационными; регистрации и production-авторизации в этом MVP нет.
