# Проверка объединённого приложения

## Frontend после интеграции · Windows · 23 сентября 2026

- Node.js 24.19.0. `pnpm check`: 13 frontend-тестов, 36 backend-тестов, 14 HTTP-интеграционных тестов и TypeScript обоих проектов. `pnpm build:all`: backend и Next.js. В окружении Codex npm добавлен в PATH процесса через `pnpm --package=npm@11 dlx -c "pnpm check"` (аналогично для сборки).
- Исправлен переносимый запуск интеграционных тестов; временные SQLite-файлы удаляются после закрытия приложений и хранилищ, что требуется Windows.
- Браузер, отдельная тестовая БД: бриф → явный AI fallback → карточка → подтверждение → публикация → предложение от Data Nomads → ручной выбор → принятие этапа → 100 XP после перезагрузки. Выбранная команда сохраняется в текущей вкладке.
- Проверены переключение на Pixel Steppe и независимые отклики/XP; на мобильном экране 390 × 844 нет горизонтального переполнения, выбор команды доступен через меню.
- После удаления поля данных редактор показывает preview 80, подтверждённый черновик 0, публикацию 100. После сохранения черновика каталог сохраняет прежний снимок.
- Две вкладки: конфликт заголовков блокирует сохранение, показывает оба варианта и сохраняет независимую правку компании из новой серверной версии. После ручного выбора сохранены нужный заголовок и обе независимые правки.
- Диалоги ухода из брифа и предложения оставляют введённый текст при выборе «Продолжить редактирование». Перезагрузку/закрытие вкладки защищает `beforeunload`; поведение системного предупреждения зависит от браузера. Несохранённый текст не записывается в постоянное хранилище браузера.
- AI live/fallback проверены через локальный HTTP-провайдер, включая отказ при настроенном ключе. Внешняя модель не вызывалась: в окружении нет ключа. API-контракт, зависимости и формат пользовательской БД не изменены.

## Предыдущая проверка интеграции

Проверка 23 сентября 2026, macOS, Node.js 24.19.0. Ветки `backend` и `frontend` объединены; данные интерфейса обслуживает настоящий Fastify API с SQLite.

## Автоматические проверки

- `pnpm check`: frontend business rules, проверка TypeScript обоих проектов, backend API/SQLite/AI/client tests и HTTP-интеграция.
- `pnpm build:all`: production-сборки backend и Next.js.
- `npm run export:openapi --prefix backend`: актуальность API-контракта.
- HTTP-интеграция покрывает низкий рейтинг, сохранение компании и девяти полей, черновик/публикацию, конфликт версий, ручной выбор, повторное подтверждение XP и AI fallback. Тесты потери ответов проверяют безопасные повторы записи и отсутствие дублей.

## Проверено в браузере

- Каталог загрузился из backend; пять исходных опубликованных карточек имеют рейтинги 20/40/70/90/100.
- Пример брифа → шесть уточняющих вопросов через `/api/brief/analyze` с явной меткой «Демо AI».
- Заполнение редактируемой карточки, ручное подтверждение, публикация с рейтингом 100.
- Отправка предложения от серверной команды Qadam; ручной выбор бизнесом; отдельное принятие этапа.
- Перезагрузка страницы сохранила новую карточку, предложение и 100 XP команды в SQLite.
- На ширине 453 px горизонтального переполнения нет, меню сворачивается. В журнале браузера отсутствуют ошибки и предупреждения приложения.
- Фильтр «Черновик» показывает карточку с рейтингом 20; кнопка предложения остаётся доступной.
- Занятый порт останавливает общий launcher с сообщением о необходимости выбрать свободные порты.

## Границы проверки

Реальный внешний AI-провайдер не вызывался. Его транспорт, некорректные ответы, таймауты и проверка фактов покрыты локальными HTTP-тестами; реальный UI проверен с отсутствующим ключом и серверным fallback. Роли остаются демонстрационными; регистрации и production-авторизации в этом MVP нет.
