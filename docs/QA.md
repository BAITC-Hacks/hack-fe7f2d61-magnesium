# Проверка объединённого приложения

Проверка 23 сентября 2026, macOS, Node.js 24.19.0. Ветки `backend` и `frontend` объединены; данные интерфейса обслуживает настоящий Fastify API с SQLite.

## Автоматические проверки

- `pnpm check`: успешно, 57 тестов (11 frontend, 36 backend, 10 HTTP-интеграционных), проверка TypeScript обоих проектов.
- `pnpm build:all`: production-сборки backend и Next.js прошли успешно.
- `npm run export:openapi --prefix backend`: актуальность API-контракта.
- HTTP-интеграция покрывает низкий рейтинг, сохранение компании и девяти полей, черновик/публикацию, конфликт версий, ручной выбор, повторное подтверждение XP и AI fallback. Тесты потери ответов проверяют безопасные повторы записи и отсутствие дублей.

## Проверено в браузере

- Каталог загрузился из backend; пять исходных опубликованных карточек имеют рейтинги 20/40/70/90/100.
- Пример брифа → шесть уточняющих вопросов через `/api/brief/analyze` с явной меткой «Демо AI».
- Заполнение редактируемой карточки, ручное подтверждение, публикация с рейтингом 100.
- Отправка предложения от серверной команды Qadam; ручной выбор бизнесом; отдельное принятие этапа.
- Перезагрузка страницы сохранила новую карточку, предложение и 100 XP команды в SQLite.
- На ширине 453 px горизонтального переполнения нет, меню сворачивается. В журнале браузера отсутствуют ошибки и предупреждения приложения.
- Фильтр «Черновик» показывает карточку с рейтингом 20; кнопка предложения остаётся доступной.
- Занятый порт останавливает общий launcher с сообщением о необходимости выбрать свободные порты.

## Дополнительная проверка с настоящим OpenAI

23 сентября 2026 проверена объединённая версия `441816d` с настроенным серверным ключом. Старый процесс backend заменён актуальной сборкой: до перезапуска он возвращал 404 на новый `/api/brief/analyze`.

- Из UI отправлен синтетический бриф магазина Qala. Через Next.js proxy и `/api/brief/analyze` получены четыре уточняющих вопроса настоящего провайдера; интерфейс показал «AI-АНАЛИЗ».
- Введены ответы и недостающие сведения; после ручного подтверждения опубликована карточка «Qala: удержание клиентов — live AI» с рейтингом 100/100.
- Команда Qadam отправила предложение; бизнес вручную выбрал её и отдельно принял демонстрационный этап. XP вырос с 0 до 100, повторная кнопка принятия исчезла.
- Backend остановлен и запущен заново с той же SQLite-базой. После перезагрузки страницы карточка, отклик, выбор и принятый этап сохранились; в «Моя команда» осталось ровно 100 XP.
- Журнал браузера после сценария не содержит ошибок и предупреждений.

## Границы проверки

Настоящий AI проверен на одном синтетическом брифе в UI; содержание вопросов и время ответа могут меняться. Ошибочные ответы, таймауты и проверка фактов дополнительно покрыты локальными HTTP-тестами. Роли остаются демонстрационными; регистрации и production-авторизации в этом MVP нет. Показ запланирован с ноутбука; публичный хостинг не настраивался.
