# SkillArena Backend Implementation Plan

**Goal:** Ship the official hackathon workflow as an independently runnable backend.

**Architecture:** Fastify REST API with SQLite, isolated from frontend files. Strict schemas drive API validation and OpenAPI. Versioned drafts and published snapshots preserve human approval boundaries.

**Tech stack:** Node.js 24+, TypeScript 5.9, Fastify 5, TypeBox 0.34, node:sqlite, node:test through tsx.

**Spec:** `docs/backend-design.md`

## Global constraints

- Official brief takes precedence; work on `backend` only.
- No score-based exclusion from the catalog or proposals; no automatic team selection.
- AI cannot create facts or approve/publish cards. Fallback must be disclosed.
- Keep secrets, SQLite databases and generated build output out of Git.
- Demo identities are not production authentication.
