# SkillArena AI · HackAlem

Фронтенд команды Magnesium. Работаем по [официальному кейсу](https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k/preview?tab=t.0): превращаем короткий бизнес-бриф в понятную задачу, повышаем её рейтинг за подтверждённые сведения, публикуем в открытом каталоге и соединяем бизнес со студенческими командами через ручной выбор.

> После сверки с организаторским документом команда выбрала официальный кейс вместо первоначальной концепции AI-симуляций. Бренд SkillArena сохранён. В этой ветке нет Mission / Proof Mode: это не обязательный сценарий текущего кейса.

## Запуск

Нужны Node.js 22.18+ (рекомендуется 24 LTS) и pnpm 11.19.0. При необходимости установите pnpm: `npm install -g pnpm@11.19.0`.

```bash
git clone https://github.com/BAITC-Hacks/hack-fe7f2d61-magnesium.git
cd hack-fe7f2d61-magnesium
git switch frontend
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Ключ AI не нужен для демонстрации.

```bash
pnpm test       # бизнес-правила, валидация AI, безопасность URL, данные
pnpm typecheck  # TypeScript
pnpm build     # production-сборка
pnpm start     # запуск готовой сборки
```

## Что работает

- Конструктор: свободный ввод → 3–9 уточняющих вопросов → редактируемая карточка → ручное подтверждение → публикация.
- Девять полей карточки, название, компания и тема; сохранение неопубликованного черновика.
- Рейтинг 0–100 с расшифровкой, пропущенными полями, пересчётом и уровнями готовности.
- Общий каталог, сортировка по рейтингу, поиск, фильтры по теме и готовности.
- Отклик: идея, план, срок и HTTP(S)-ссылка на прототип; можно отправить несколько предложений.
- Кабинет бизнеса: сравнение предложений, выбор одной/нескольких команд или отклонение всех; без автоматического назначения.
- Ручное принятие результата этапа и +100 XP команде, без повторного начисления.
- Профиль команды и состояние откликов; данные переживают перезагрузку страницы.
- Адаптивная вёрстка, клавиатурная навигация, modal dialog, reduced motion, загрузка и ошибки.

## Границы демо

Это **frontend MVP**. Задачи и отклики хранятся в `localStorage` одного браузера. Переключатель «Команда / Бизнес» позволяет показать обе роли без регистрации; это не система авторизации. Разные устройства и браузеры не синхронизируются. Все начальные компании, команды, контакты, предложения и прототипы — синтетические примеры.

По умолчанию AI работает как явно подписанная детерминированная заглушка: она выбирает вопросы для пустых полей, учитывает retention-контекст, не заполняет ответы за пользователя и не выдаёт примеры за полученные от AI факты. Кнопки «Подставить» и «Заполнить ответами из демо-примера» — явные действия ведущего демо.

Реальный анализ подключается через `NEXT_PUBLIC_BRIEF_API_URL`. При ошибке внешнего API предлагаются повторный запрос или **явный** переход на демо-вопросы. API-ключ провайдера должен оставаться на бэкенде.

## Прозрачная формула рейтинга

Баллы получает непустое поле **только после подтверждения человеком**. Содержательность проверяет представитель бизнеса; модель не объявляет свои догадки фактами. Формула детерминирована, рейтинг не зависит от компании или количества откликов.

| Показатель                      |     Вес |
| ------------------------------- | ------: |
| Контекст + потребность          | 10 + 10 |
| Данные и материалы              |      20 |
| Ожидаемый результат             |      15 |
| Критерии успеха                 |      15 |
| Ограничения                     |      10 |
| Пользователи                    |      10 |
| Контакт + формат взаимодействия |   5 + 5 |
| **Всего**                       | **100** |

Уровни: **0–39** — черновик, **40–69** — рабочая, **70–89** — готовая, **90–100** — приоритетная. Редактирование снимает подтверждение с изменённого поля. После повторного подтверждения рейтинг обновляется. Опубликованная версия не меняется, пока бизнес не подтвердит изменения.

Низкий рейтинг никогда не скрывает опубликованную карточку и не блокирует отклик. «Черновик» как уровень готовности — не то же самое, что неопубликованный черновик: первый доступен всем после ручной публикации, второй находится только в кабинете бизнеса.

Каталог сортируется по рейтингу по убыванию; при равных баллах — по дате создания. XP команды начисляется отдельно: **100 XP за принятый бизнесом этап выбранной команды**, независимо от рейтинга задачи. Повторное подтверждение не увеличивает XP.

## Подключение AI

Скопируйте `.env.example` в `.env.local`, задайте адрес backend и перезапустите dev-сервер:

```dotenv
NEXT_PUBLIC_BRIEF_API_URL=http://localhost:8000/api/brief/analyze
```

В frontend нет собственного API-сервера или orchestration. [Контракт запроса/ответа, промпт и правила обработки ошибок](docs/FRONTEND_HANDOFF.md) вынесены отдельно. Для демо по официальному кейсу допустима заглушка, если показаны промпт, формат данных и обработка некорректного ответа.
