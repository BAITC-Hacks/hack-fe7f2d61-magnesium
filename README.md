# SkillArena AI · HackAlem

Объединённый frontend + backend команды Magnesium. Сценарий: бизнес-бриф → уточняющие вопросы → редактируемая карточка → ручное подтверждение → рейтинг → публикация → предложение команды → ручной выбор → подтверждённый этап и XP.

Перед разработкой прочитайте [правила веток и слияния](BRANCH_RULES.md): зоны ответственности, изменение API, проверки и синхронизация `frontend`/`backend` с `main`.

## Быстрый запуск

Нужны **Node.js 24+** и **pnpm 11.19.0** (`npm install -g pnpm@11.19.0`). Из корня репозитория на ветке `main`:

```bash
pnpm install --frozen-lockfile
npm ci --prefix backend
pnpm dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Одна команда запускает Next.js и Fastify; Ctrl+C останавливает оба. API работает на порту 3001, [Swagger — /docs/](http://127.0.0.1:3001/docs/). Если порты заняты:

```bash
FRONTEND_PORT=3100 BACKEND_PORT=3101 pnpm dev
```

Настройки не обязательны. Чтобы подключить AI, скопируйте `backend/.env.example` в `backend/.env` и задайте `OPENAI_API_KEY`. Без ключа backend возвращает вопросы по шаблону, а интерфейс явно показывает «Демо AI». Секреты не должны попадать в `NEXT_PUBLIC_*`.

## Что подключено

- Каталог, черновики, предложения, ручные решения, подтверждённые этапы и XP хранятся в **SQLite на backend** и доступны из разных браузеров.
- В интерфейсе используются реальные серверные команды. Демо-роль студента — первая команда из API; бизнес — `business-demo`.
- Изменения опубликованной задачи сохраняются отдельным черновиком. Каталог обновляется только после повторного ручного подтверждения и публикации.
- Рейтинг 0–100 начисляется за заполненные подтверждённые поля. Карточки с рейтингом 0–39 также открыты для откликов.
- Бизнес может выбрать несколько команд. XP начисляется только после принятия этапа; повторное нажатие не начисляет баллы второй раз.
- Ошибки API отображаются явно. Введённые данные формы сохраняются при ошибке запроса; конфликт версий не перезаписывает изменения другого редактора.
- Браузер обращается к `/api/*` через Next.js proxy. При возврате фокуса данные загружаются заново; мгновенных push-обновлений нет.

База по умолчанию: `backend/data/skillarena.sqlite`. Начальные задачи и команды — синтетические примеры. Старое `localStorage` frontend-демо не импортируется автоматически. Переключатель роли и заголовки идентичности — **демо без регистрации**, не production-авторизация.

## Проверки

```bash
pnpm check       # frontend, backend, TypeScript и интеграционные HTTP-тесты
pnpm build:all   # production-сборки backend и frontend
```

Интеграционные тесты поднимают отдельный сервер с временной БД в памяти: публикация задачи с низким рейтингом, отклик, ручной выбор, однократные XP, повторная загрузка, независимость черновика от публикации, конфликт версий и AI fallback. Пользовательская БД не затрагивается.

Для production-сборки после `pnpm build:all` запустите `npm start --prefix backend` и `pnpm start` в двух терминалах. Если backend расположен по другому адресу, задайте `BACKEND_URL` **при сборке** Next.js. Для отдельных dev-процессов: `pnpm dev:backend` и `pnpm dev:frontend`.

## Структура

- `app/`, `components/` — Next.js, React, интерфейс.
- `lib/workspace-api.ts` — преобразование frontend/backend контрактов и серверные операции.
- `lib/brief-api.ts` — анализ брифа и явный demo fallback.
- `backend/` — Fastify, SQLite, AI, API и тесты.
- [Backend API и запуск](backend/README.md), [OpenAPI](backend/openapi.json).
- [Интеграция](docs/frontend-integration.md), [сценарий проверки](docs/DEMO.md).

Рейтинг: контекст 10, потребность 10, данные 20, результат 15, критерии 15, ограничения 10, пользователи 10, контакт 5, взаимодействие 5. Уровни: 0–39 черновик, 40–69 рабочая, 70–89 готовая, 90–100 приоритетная. Прогресс команды учитывается отдельно: 100 XP за принятый этап.
